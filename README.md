# Terraform Labs

Este repositório será utilizado para armazenar meus estudos e laboratórios práticos de Terraform.

O objetivo é praticar a criação, configuração e gerenciamento de infraestrutura como código, aplicando conceitos como:

- Providers
- Variables
- Locals
- Outputs
- Resource Groups
- Redes virtuais
- Máquinas virtuais
- Terraform State
- Modules
- Remote Backend
- Ambientes de desenvolvimento, homologação e produção

Cada laboratório será organizado em uma pasta separada, contendo os arquivos Terraform, instruções de execução e uma explicação dos recursos implementados.

## Objetivos

- Desenvolver experiência prática com Terraform
- Criar infraestrutura de forma automatizada
- Aplicar boas práticas de Infrastructure as Code
- Praticar a integração do Terraform com o Microsoft Azure
- Documentar minha evolução nos estudos

## Comandos principais

```bash
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform destroy
